# Acceptance Criteria

Every deliverable must satisfy all of these before the loop ends.

## Visual & Layout
- Correct hierarchy, section order, alignment, grid, spacing rhythm

## Typography
- Closest matching fonts, sizes, line-heights, weights

## Responsive
- No horizontal scroll
- Correct stacking on mobile
- Usable navigation on mobile

## Interactions
- Hover and focus states present
- Clean transitions
- Functional form UI

## Engineering
- Maintainable, well-scoped components
- Accessible semantics
- Good performance defaults
